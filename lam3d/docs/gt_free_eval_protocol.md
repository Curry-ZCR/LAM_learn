# 无真值条件下的协方差调制评测协议

> 适用对象：LAM(arXiv:2502.17796)单图 → 3DGS 头部数字人的推理期协方差调制改造（不重训练 LAM）。
> 硬约束：渲染器只接受 `(q, s)` 回写；单次表情 splat ≤ 30 ms；无同身份带表情真值；20018 高斯一一绑定 FLAME Loop 细分顶点（顶点绑定，无面局部帧），p50 轴长比 3.37 / p90 83，80.4% 薄片。
> 本文档所有数字均为 RTX 4090 上 messi 资产（20018 → 清理后 19494 有效高斯，39904 面，平均一环边长 ē = 5.308 mm）+ 9 个 ARKit preset + 5 个合成向量实测，来源 /tmp/cov_protocol_stats.json、/tmp/cov_reference.json、/tmp/cov_offline.json。

## 0. 先给判断（六条）

1. 参考系 A / C（像素 PSNR/SSIM/LPIPS）必须退出排序角色。实证依据是"高斯重叠吸收"：像素 flicker 四方法 2.2482 / 2.1702 / 2.1732 / 2.1796，跨度 0.078（3.5%），而几何指标跨度是 4–5 倍量级。像素指标只能降级为回归门控（"不得比 LAM 更差超过噪声"）。
2. 主指标应当是几何量，但不是现有的全部：现有 `rigid_err` + `delta_protrusion_over_edge` 是全部候选中唯二跨 5 个输入向量排序 100% 稳定的指标，可作主轴；`shape_err` 是代价项（要与其他项联立，否则可用"缩水"作弊）；`normal_angle` 的绝对量已证伪（四方法 55.5–57.3° ≈ 随机 57.3°），只能改用差分形式 `normal_track`。
3. 新增指标里最关键的只有一个：真正的薄片穿透率 penetration（椭球 × 网格 SDF 求交）。现有 `protrusion = s_max·sinθ / ē` 是解析近似，忽略网格曲率与相邻面，且存在"缩小椭球也能降低突出"的作弊通道。
4. 代理真值不能解决排序问题，但能解决阈值定标问题。正确用法不是"拿它当真值算分"，而是合成故障注入（synthetic fault injection）：在伪 GT 上注入已知量级的几何错误，标定"多少度的 rigid_err 会被人眼看见"，把无量纲指标翻译成"可见性当量"。
5. 统计单位必须是空间分块，不是高斯。实测 ICC = 0.12–0.50，design effect 10–72；直接逐高斯 i.i.d. 检验会把显著性高估 3–8 倍。
6. 必须先说的坏消息：RotSync 的改善全部集中在主体，尾部几乎没动。extreme 向量上 rigid_err p50 15.73° → 3.14°（−80%），但 p99 150.73° → 143.12°（仅 −5%）；而 VTP 的 p99 是 99.55°，尾部反而最优。p50 型验收会放过一个"仍有 1% 高斯在 143° 撕裂"的方案。验收判据必须同时含 p50 与 p99 双门，且无解区需要 fallback。

## 1. 客观指标补强

### 1.1 指标分层（先定角色，再谈权重）

每一层只承担一种职责，避免"用像素指标排序、用几何指标解释"这种越权。

| 层 | 职责 | 指标 | 是否用于排序 |
|---|---|---|---|
| L0 契约/健康度 | 一票否决 | compute_splat p95、NaN、det J_v ≤ 0 比例、轴倍率越界率、显存增量 | 否决用 |
| L1 几何保真 | 主排序 | rigid_err、penetration、delta_protrusion、normal_cov_err、saturate_frac | 是（主） |
| L2 定义级代价 | 惩罚项 | shape_err、shear_deficit、coverage_ratio Ω | 是（只扣分不加分） |
| L3 表观/时域 | 门控 + 灾难检测 | warp-error、flicker 频谱、PSNR/SSIM/LPIPS | 否（仅门控） |

### 1.2 现有指标：加权建议（含理由）

| 指标 | 建议权重 | 方向 | 保留理由 | 注意 |
|---|---|---|---|---|
| rigid_err（分块中位） | 0.35 | 降 | 唯一直接测"面内旋转是否被正确实现"；实测跨 5 向量排序 100% 稳定；LAM 7.76 / TGA 6.09 / RotSync 1.54 / VTP 1.54 | 必须报 p50 和 p99（见 §0.6） |
| delta_protrusion_over_edge | 0.15 | 降 | 跨 5 向量排序 100% 稳定（lam −0.0133 < vtp −0.0003 ≈ rot −0.0001 < tga +0.0241） | 有作弊通道：LAM 因缩小椭球得到负值，必须与 coverage_ratio 联立 |
| shape_err | 0.10（惩罚） | 降 | 唯一量化"丢 shear/stretch"的定义级代价 | 只扣分。extreme 上 TGA 0.8030 优于 LAM 0.8429 → 排序会翻转，说明它是代价项不是质量项 |

### 1.3 必须新增的指标（按优先级）

#### (N1) 薄片穿透率 penetration —— P0，最重要

为什么必须新增：`protrusion = s_max·sinθ/ē` 是解析近似，只看薄轴与法向的夹角，完全不知道网格在局部往哪弯。真实视觉故障是"薄片从皮肤里斜插出来"，这是椭球与网格的拓扑关系，不是夹角关系。它还有作弊通道：把椭球整体缩小（LAM 的 2×2 面积调制 + tanh 软截断就是这么做的）也能降低 s_max·sinθ，代价是覆盖空洞。

定义（每高斯 i，表情帧 t）：

```
u_i   = 最小特征值对应轴（薄轴，单位向量）
σ_i   = 最长半轴长 = s_max
P     = { μ_i + k·σ_i·u_i : k ∈ {−3,−2,−1,0,+1,+2,+3} }   # 7 点，覆盖 6σ 支撑
d(p)  = signed_distance(p, M_t)      # BVH over FLAME Loop 细分三角面，M_t 为表情网格
embedded_i  = #{p : d(p) < 0} / 7
pen_depth_i = max(0, −min_p d(p)) / ē          # 穿透深度，以平均边长归一
flip_i      = 1[ sign(d(−3σ)) ≠ sign(d(+3σ)) ] # 薄片两端被表面切开 → 斜插
penetration_rate = mean_i( embedded_i > 0.5 )  # "整片插进肉里"的占比
flip_rate        = mean_i( flip_i ∧ embedded_i > 0 )
```

性能：19494 高斯 × 7 点 = 13.6 万次 BVH 查询。用 trimesh.proximity.signed_distance（配 rtree）或 igl.signed_distance，单帧 ≈ 1.5–3 s，离线评测可接受。
期望信号：中性帧 embedded p50 应 ≈ 0.5（薄片对称跨表面）；RotSync 应保持 ≈ 0.5；TGA 的 flip_rate 应显著高于 RotSync；LAM 的 embedded 分布应偏向一侧，因为其面积调制是单向压缩。
验收形式：penetration_rate 与 flip_rate 都做差分校准（表情 − 中性），因为中性帧绝对值是资产固有属性（与 80.4% 薄片相关），不是方法造成的。

#### (N2) 法向协变误差 normal_cov_err —— P0（对应改进方向 (a)）

这是唯一能把"RotSync 的定义级偏差"量化成角度的量。RotSync 给出的新法向是 R·n₀；严格协变解是 normalize(J_v^{-T} n₀)。二者之差就是"丢掉 shear 之后法向错在哪"。

```
n*_i = normalize( J_v,i^{-T} · n_i^0 )     # 严格协变法向（J_v 由 TGA 的 vertex_jacobians 提供）
ε_i  = angle( u_i^t , n*_i )               # 单位 deg
Δε   = ε_ROT − ε_TGA                       # shear 贡献量
```

判据价值：若 Δε 的 p90 < 2°，则改进方向 (a)（法向协变修正）与 (c)（SPD 测地插值）在可见性意义上都不值得做 —— 一个数砍掉两条研发路线，建议立刻测。
前提：J_v 在 0.12–0.49% 高斯上 det ≤ 0，此时 J^{-T} 不可用 → 伪逆 + 该子集单独报 invalid_rate。

#### (N3) 表情语义一致性 semantic_consistency —— P1

目的：抓"幅度对了、方向反了"这类任何均值指标都发现不了的灾难。

流程：
1. 取 20 个解剖上有意义的 ARKit 通道（jawOpen, mouthSmile_L/R, mouthPucker, mouthFunnel, cheekPuff, browDown_L/R, browInnerUp, browOuterUp_L/R, eyeBlink_L/R, eyeSquint_L/R, noseSneer_L/R, mouthPress_L/R）。
2. 每通道单独置 1（其余中性）→ 位移场 δ_k ∈ R^{N×3}。
3. 对解析解 Σ_exact 跑同一流程得 δ*_k。
4. 通道签名 ρ_k = cos( vec(δ_k), vec(δ*_k) )；semantic_score = mean_k ρ_k；reversed_frac = mean_k(ρ_k < 0)。
5. 门控：reversed_frac > 0.05 直接判不合格。
6. 附加 amplitude_ratio_k = |δ_k| / |δ*_k|，检测"表情幅度被过度衰减"（RotSync 在 45° 饱和时会出现）。

为什么不用"与 ARKit 官方对标"：lam3d 的 arkit_offsets 与 ARKit 官方 52 通道定义并非一一映射（不同厂商 blendshape 语义有差），"与官方对标"会引入映射误差。闭环到自家解析解更干净，且能复用参考系 C 的代码。

#### (N4) 覆盖率守恒 coverage_ratio Ω —— P0（防作弊）

```
Ω = Σ_i |det Σ_i^t|^{1/2} / Σ_i |det Σ_i^exact|^{1/2}
```

- RotSync 构造上 Ω = 1.000（正交变换保行列式）。
- LAM 的 tanh 软截断会 Ω < 1；TGA 的 clamp 产生 Ω 偏小 + 少数极端放大。
- 要求 0.97 ≤ Ω ≤ 1.03。这条把 delta_protrusion 的作弊通道堵死：不允许靠"整体缩水"换低突出。

#### (N5) 饱和率 saturate_frac —— P0（RotSync 专属风险）

```
saturate_frac = mean_i( |Δθ_i| ≥ 0.98 · max_angle_deg )
```

现状 max_angle_deg = 45，极端表情上有一批高斯被硬卡在 45° → 视觉上是"该动的没动"，比"动错"更刺眼（对比度损失而非局部噪声）。
要求 ≤ 2%；2–5% 需自适应 max_angle_deg（按表情幅度线性放大到 60–75°）；> 5% 判不合格。与 semantic_consistency 的 amplitude_ratio 交叉验证。

#### (N6) 时域 flicker：从"亮度差"换成"运动补偿 warp error" —— P1

现有 jawOpen flicker 四方法 2.1702–2.2482，跨度 3.5%，已证无区分度。原因是高通量重叠：相邻高斯覆盖同一像素，几何抖动被平均掉。替代方案：

(a) 运动补偿 warp error（主推）

```
E_warp(t) = mean_p | I_t(p) − I_{t−1}(p + f_t(p)) |
f_t = 由 FLAME 顶点运动 + 相机投影得到的稠密光流（不用估计光流，直接由几何算出）
```

把"表情本身引起的变化"减掉，剩下的才是"方法引起的抖动"。这是唯一有希望把 0.02 dB 级别的差异放大到可测的像素级手段。成本：需要 z-buffer 与逐像素几何流，约 30 行 numpy + 一次投影，单序列 < 10 s。

(b) 闪烁频带能量比

```
R_flicker = Σ_{f∈[8,25]Hz} |FFT(I_t(p))|² / Σ_f |FFT(I_t(p))|²    # 每个像素，取 ROI 中位
```

人眼对 8–25 Hz 亮度抖动最敏感（临界闪烁频率附近）；"帧内几何错误"时这一项不敏感，所以它能分离"静态几何错"与"动态抖动"两类缺陷。

(c) 帧差能量比 ‖I_t − I_{t−1}‖² / ‖I_t^exact − I_{t−1}^exact‖²，>1 表示比解析解更抖。

仍建议 (a)(b)(c) 全部进 L3 门控而非排序：像素级差异的物理来源（重叠平均）没变，warp error 只是部分绕开。

### 1.4 一条被忽略的指标：无解区的行为

已知 0.2–0.4% 顶点（46–76 个）一环面旋转两两夹角中位 176°，任何平均法无定义。当前 coherence_gate 默认关闭。必须新增两个量：

- unresolved_rigid_p99：在"一环面旋转两两夹角 > 150°"子集上单独算 rigid_err。extreme 下整体 p99 是 143°，几乎可以确定该子集贡献了绝大部分尾部。
- gate_trigger_frac + gate_cost：打开 coherence_gate 后触发门控的高斯占比，以及全身 shape_err 的上升量。要求 gate_cost ≤ 1%。

建议的混合策略（可能是真正的最优解，需验证）：

```
conf_i < τ  →  回落到 LAM 原版调制（薄片斜插但至少不撕裂）
conf_i ≥ τ  →  RotSync
```

理由：LAM 在尾部（150°）与 RotSync（143°）几乎一样差，而无解区里"部分旋转"可能比"完全不旋转"更糟。这条要作为 M4 候选设计写进验收。

### 1.5 排序机制：不要用加权和

加权和对权重敏感、可被单指标刷分、且掩盖"哪个维度退让了"。建议门控 + Pareto 支配 + 显著性三步：

1. 门控（L0 + Ω + saturate_frac + reversed_frac）：任一不过 → 淘汰。
2. Pareto 支配：A 支配 B 当且仅当 A 在 5 个 L1 指标上全部不差，且至少 3 个显著更好。
3. 单分数仅作汇报：ρ_m = M_m(candidate)/M_m(LAM)（全部越小越好），S = Σ_m w_m·clip(1−ρ_m, −1, 1)。

以 extreme 实测举例（仅已测 3 项、权重重归一）：
```
ρ_rigid = 3.136/15.734 = 0.199 → 0.801
ρ_dprot = 0.019/0.089  = 0.213 → 0.787
ρ_shape = 0.8722/0.8429= 1.035 → −0.035
S = (0.35·0.801 + 0.15·0.787 + 0.10·(−0.035)) / 0.60 = 0.658
```
VTP 同法得 0.657（rigid 3.149）→ 两者在 S 上等价，因此 VTP 无法通过"必须显著优于 RotSync"这一条（见 §5）。

## 2. 代理真值方案

### 2.1 先给结论：能绕开吗？

部分能，但绕开的不是你以为的那部分。把"真值"拆成三种：

| 类型 | 内容 | 能否由多视角数据集提供 | 对本题是否有用 |
|---|---|---|---|
| T1 几何真值 | 该人物在该表情下的真实表面 | 可以（多视角重建 / 高精度扫描） | 只能定标，不能排序 |
| T2 表观真值 | 该人物在该表情下的真实照片 | 可以 | 无用：像素指标对方法差异不敏感（已实证 0.02 dB） |
| T3 协方差真值 | 每个高斯"正确"的 Σ | 不存在 | 不存在 |

关键洞察：你缺的不是图像真值，是"Σ 的正确性"这个概念的锚。而 T3 不存在 —— Σ 本身是渲染器的自由度，"正确的 Σ"只在"能重现同一表面"的意义上有定义。所以代理真值的正确用途是：

> 用多视角人物的"表面"作为锚，把几何指标（度、无量纲）翻译成"表面偏差毫米数"和"可见性等级"，而不是用于给方法排高低。

### 2.3 操作流程

```
Step 0  身份偏移校准（必须先做，否则后面全是噪声）
  取 subject S 的中性帧 → LAM 单图重建 → G_S（20018 高斯 + FLAME betas β_LAM）
  载入数据集给的 β_data，FLAME(β_LAM) 与 FLAME(β_data) 顶点差 δ_id
  判据：median(δ_id) > 0.3·ē（约 1.6 mm）→ 该 subject 不可用于伪 GT，换人
  原因：δ_id 污染所有"顶点法向/一环"类指标，且与方法无关

Step 1  表情参数迁移
  用数据集的 pose/jaw/expr（保留 LAM 的 β，身份不能换）
  arkit_offsets 语义对齐检查：20 个通道各置 1，人工看 3 帧，确认方向与幅度
  判据：某通道位移方向与数据集标注相反 → 该通道剔除（记录到附录）

Step 2  伪 GT 构建（三条并行）
  (a) 表面 GT：数据集多视角重建网格 M_t（或 FLAME(β_data, 表情) + 扫描残差）→ 提供"面在哪"
  (b) 协方差 GT：Σ_exact = J_v Σ0 J_v^T（同参考系 C，但表情是"真表情"）
  (c) 表观 GT：数据集相机位姿下的多视角图像（仅灾难检测，不排序）

Step 3  四方法在 G_S 上跑，得到 (q, s)
Step 4  对齐：FLAME 拓扑一致 → 顶点一一对应，无需配准；仅需 Procrustes（刚性+尺度）把 G_S 顶点拉到 M_t 坐标系
Step 5  计算全部指标，以"方法 − LAM"配对差分上报（消掉 δ_id 常数项）
```

### 2.4 伪 GT 的偏差来源（逐项）

| 编号 | 偏差源 | 量级线索 | 量化方法 | 缓解 |
|---|---|---|---|---|
| D1 | 身份偏差（β_LAM ≠ β_data） | 未知，与 subject 强相关 | Step 0 的 median(δ_id) | 换 subject；或只用差分 |
| D2 | 表情语义映射偏差（arkit_offsets vs 数据集 blendshape 定义） | 单通道可达 10–30° 方向偏差 | 单通道置 1 的位移场 cos 相似度 | 剔除低相似通道 |
| D3 | 相机/裁剪偏差 | 致命：LAM 的 512 白底 crop 不可复现（head_utils.py:61-118 center_crop_according_to_mask 的随机 enlarge_ratio） | 复现性实验：同输入跑 3 次看 crop 框 | 必须自实现确定性 crop + 存盘相机 |
| D4 | 纹理/光照 | 数据集 studio 光 vs LAM 顶点色 67.8% 烘焙 + 32.2% f_dc 兜底 | 中性帧 PSNR 上限 | 只做差分，不比绝对 |
| D5 | 背面覆盖 | LAM 单图只见到 1 个视角，背面是猜的 | 按可见性分区报指标 | 分区（正面/侧面/背面）上报 |
| D6 | 时间同步 | 视频帧 ↔ 表情参数 | 交叉相关对齐 | 手动标注 3 个关键帧 |
| D7 | 毛发/衣物 | 高斯只覆盖 FLAME 表面 | — | 掩膜掉非皮肤区 |

核心判断：D1/D2/D3 合起来会让伪 GT 上的绝对误差产生与方法无关的常数偏移。因此：

- 伪 GT 只能做配对差分（D5–D7 被消掉）；
- 伪 GT 不能复现已有排序（那部分已做过）；
- 若强行用伪 GT 排序，预计得到"方法无关常数项主导、排序噪声大于信号"，与参考系 A 的失败模式相同（跨度 5.3e-4 dB）。

### 2.5 真正该用伪 GT 做的事：合成故障注入

本节最有价值的建议：不要拿伪 GT 当真值算分，拿它当"可见性标尺"。

```
for 注入水平 L ∈ {5°, 10°, 20°, 40°, 80°} × 高斯占比 r ∈ {1%, 5%, 20%, 50%}:
    在 RotSync 结果上，对随机 r 比例的高斯施加 ±L 的随机额外旋转（模拟"该转没转对"）
    → 得到 20 个"已知劣化"样本
    for 每个样本:
        测 rigid_err / penetration / delta_protrusion / warp_error
        测 2AFC 可见性（或至少：与未注入版的像素差 + 专家 3 人盲评）
    → 拟合 "指标值 → 可见性概率" 曲线
```

产出：
1. 每个指标的可见性当量，例如"rigid_err p50 每上升 3° ≈ 10% 被试可察觉"。
2. 指标的可检测下限：低于多少时 2AFC 偏好率与 50% 不可区分。
3. 反过来给 §5 的阈值提供经验依据，而不是拍脑袋。

预期（待验证）：penetration 与 warp_error 的可见性斜率最陡，rigid_err 中等，shape_err 最平（人眼对椭球胖瘦不敏感，对穿出敏感）。若成立，§1.2 权重要往 penetration 倾斜。

成本：注入 20 个样本 × 单帧评测约 1 小时；专家盲评 3 人 × 20 对约 40 分钟。整个协议里性价比最高的一步，建议最先做。

## 3. 主观评测协议

### 3.1 方法选择：2AFC 强制选择 + catch trial

不用 MOS：方法间差异小（0.02 dB 级），MOS 的 1–5 量表会被个体尺度差异（被试间 σ 常达 0.8）完全淹没，且不提供"无差异"的零假设基准。也不用 3 点/5 点好坏。

用 2AFC 强制二选一：强制选择消除尺度差异、只比相对；有成熟的二项/混合模型统计；被试负担低（单试次 2–3 s）。

必须加 catch trial（相同刺激对），占 30%：这是测谎仪，用来估猜测率与位置偏好。若某被试在 catch 上"选左"比例不在 [0.30, 0.70]，或总体偏好率不在 [0.40, 0.60]，剔除该被试（预计剔除 10–15%）。

### 3.2 刺激集（控制组合爆炸）

不要做 4 方法 × 9 preset × 5 视角 = 180 个 clip。收敛为：

- 表情 6 个：neutral, jawOpen, bigSmile_L+R, mouthPucker, browDown_L+R, eyeBlink_L+R。覆盖嘴周（薄片最密集）、眼周、额部三类区域，且都有独立 ARKit 通道。
- 视角 3 个：正面 0°、3/4 侧 ±35°、仰视 −20°（看下颌缘）。仰视是"薄片穿出下颌"最容易暴露的视角。
- 共 18 个 clip，每个 2.5 s @ 60 fps 循环，首尾帧相同（无跳变）。
- 方法对只做 2 个主比较：RotSync vs LAM、RotSync vs TGA；加 1 个 VTP vs RotSync 做等价性检查。共 3 对。
- 总试次 = 18 × 3 = 54 真试次 + 30% catch = 70 试次/人，约 12 分钟（含休息）。

### 3.3 被试

- N = 32 人（含冗余；目标有效 27–28 人）。其中 24 名普通用户（无图形学背景，符合最终用户分布）；8 名专家（3D 美术 / 图形学研究生以上），单独分析，用于定性访谈与解释性分析。
- 招募要求：裸眼或矫正视力正常；无色觉异常；未参与本方法开发。
- 记录：年龄、性别、是否佩戴眼镜、日常使用 3D/游戏内容频率（作为协变量）。

样本量依据：
- 二项检验检出 p₁=0.60 vs p₀=0.50（α=0.05 双尾，power=0.8）→ n ≈ 194 独立判定/对。
- 每对每人 18 判定，被试聚类 ICC 估 0.15 → design effect = 1 + (18−1)·0.15 = 3.55 → 有效 n = 32×18/3.55 ≈ 162。
- 略低于 194，但 GLMM 比二项检验更有力（利用 clip 与表情的重复测量结构），且可把 3 对合并估计被试总体敏感度。若首轮 32 人结果落在 0.55–0.60 灰区，补招至 48 人。

### 3.4 呈现与流程

- 显示器 ≥ 27"、1920×1080 以上、sRGB 校准、固定亮度（记录 cd/m²）；距离 60 cm（用纸尺量）；
- 环境照度 < 50 lux，无窗直射；
- 刺激以原始 512×512 呈现，不缩放（避免重采样掩盖高频伪影），背景纯中灰（不是白，白会压低边缘可见度）；
- 每试次：灰屏 500 ms → 左右并排播放（同一时刻、同步启动）→ 播放 2.5 s → 被试按键（← / → / 空格=无法判断）→ 灰屏 800 ms；
- 左右位置随机平衡（每对 AB / BA 各半），且每个 clip 内平衡，防位置偏好；
- 每 15 试次强制休息 20 s（防疲劳）；
- 首 3 试次为练习（不计分），明确告知"这两段可能完全相同，如果完全相同请按空格"。

关于"无法判断"：允许，但单独统计，不并入二选一。若某对"无法判断"率 > 40%，说明该对视觉上不可区分 —— 这本身是重要结论（等价性）。

### 3.5 序列效应控制

| 效应 | 控制手段 |
|---|---|
| 顺序/学习效应 | 方法对内部 AB/BA 平衡（拉丁方在"对"层面） |
| 位置偏好 | 左右随机，且每被试内左右出现次数严格相等 |
| 疲劳/漂移 | 试次随机打乱（不用固定块），每 15 试次休息，记录试次序号作协变量 |
| 对比效应（前一个 clip 影响后一个） | 相邻试次不同表情、不同方法对（约束随机化） |
| 锚定效应 | 不展示任何"参考/原始"版本，不告知方法名与数量 |
| 期望效应 | 单盲：被试不知道实验目的；指导语只说"判断哪一段皮肤表面瑕疵更少" |
| 重复暴露 | 每个 clip 每对被试只看一次 |

指导语（固定文案，逐字念）：
> "你会看到两段完全同步的三维人脸动画，它们由同一个模型生成，区别只在皮肤表面的细节处理。请判断哪一段看起来更自然 —— 特别注意脸颊、下巴、嘴唇周围有没有细小的片状物穿出皮肤、或者表面出现不自然的褶皱和闪烁。如果两段完全一样，请按空格。"

不要说"哪一段旋转更准确" —— 会引导被试关注错误的线索。

### 3.6 分析

- 主分析：广义线性混合模型（GLMM）logistic，choice ~ method_pair * expression + view + (1|subject) + (1|clip)；报 odds ratio + 95% CI。
- 备选：每人每对算一个偏好率 → 单样本 Wilcoxon（稳健，不依赖模型）。
- 等价性（VTP vs RotSync）：TOST，等价界 ±3 个百分点（偏好率落在 [0.47, 0.53] 视为等价）。
- 专家 vs 普通：分组交互项；若专家敏感度显著更高，以专家结果作"上限"，普通用户作"实际体验"。
- 定性：专家访谈逐条记录缺陷描述，与几何指标做定性映射（哪条指标对应他们说的"穿出"）。

### 3.7 伦理与可复现

- 知情同意、可随时退出、数据匿名化；
- 每个试次的按键与反应时全部记录；RT < 300 ms 的试次标记为"疑似盲按"，做敏感性分析；
- 所有 clip 的生成脚本 + 随机种子 + 播放顺序表落盘，保证可复现。

## 4. 统计检验

### 4.1 核心原则：统计单位是空间分块，不是高斯

实证依据（extreme 向量）：

| 方法 | ICC(rigid) | ICC(shape) |
|---|---|---|
| LAM | 0.501 | 0.229 |
| TGA | 0.333 | 0.171 |
| RotSync | 0.301 | 0.118 |
| VTP | 0.316 | 0.118 |

ICC = 0.12–0.50 意味着高斯之间高度空间相关（相邻高斯共享一环面、共享 J，误差同源）。若把 19494 个高斯当独立样本：

| 配对比较 | 真实差值 | 分块 bootstrap 95% CI | i.i.d. 半宽 | design effect |
|---|---|---|---|---|
| TGA − RotSync, rigid | +14.368° | [11.610, 15.612] | 0.345° | 33.7 |
| RotSync − LAM, rigid | −17.712° | [−19.629, −13.729] | 0.347° | 72.4 |
| TGA − RotSync, shape | −0.0737 | [−0.0805, −0.0507] | 0.0046 | 10.4 |
| RotSync − LAM, shape | +0.0652 | [0.0373, 0.0648] | 0.0044 | 10.0 |

用 i.i.d. 半宽报 CI 会把置信区间缩窄 sqrt(design effect) ≈ 3–8.5 倍，等于把 p 值虚报 1–2 个数量级。

做法：
- 分块用顶点图的连通划分（当前实现 K=155 块，中位 91 顶点，min/max = 13/6036）。max 6036 的巨块需处理 → 改为等大小平衡划分（空间 k-means / 图分割，K=200–300，块大小 60–100），降低单块主导。
- 每个块内取指标中位数（对重尾稳健），得 K 个配对差。
- 所有指标、所有比较在同一块划分上做，保证配对。

### 4.2 检验流程（三级）

一级：配对分块 bootstrap

```
B = 10000 次
每次：有放回抽 K 个块（两方法共用同一索引，保证配对）→ 配对差的中位数（或均值）→ bootstrap 分布 → BCa 95% CI
判据：CI 不含 0
```
BCa 优于 percentile（对偏态/重尾更准，shape_err 明显右偏）。

二级：分块置换检验（无分布假设的交叉验证）

```
在块内随机交换方法标签（10^4 次）→ 得差值零分布 → 双侧 p
```
两者一致是必要条件；若 bootstrap 与置换结论矛盾 → 报中位数差 + 两个 CI，不下强结论。

三级：多重比较控制

- 5 个 L1/L2 指标 × 3 个方法对 = 15 个检验 → Benjamini–Hochberg FDR = 0.05。
- 不要用 Bonferroni（15 个检验会过度保守，把真实差异如 shape 的 0.065 压到不显著）。

### 4.3 报告规范

- 不报 mean ± sd。全部指标重尾（rigid_err max = 180°，shape_err max = 7.38）→ 报 median [IQR]、p90、p99。
- 每个结论必须带 effect size：
  - 分块级 d_z = mean(配对差)/sd(配对差)。实测：lam−rot rigid d_z = 0.808 (ones) / 0.899 (extreme)；rot−lam shape d_z = 0.377 / 0.568；tga−rot dprot d_z = 0.270 / 0.245。
  - 逐高斯 Cliff's δ（一致性概率），报"线性/任意方向"比例。
- 必报胜率：分块级 RotSync 优于 LAM 的块占比 = 96.8% (ones) / 97.4% (extreme)；逐高斯级 = 72.4% / 74.9%（差值 > 2° 时 56–58%）。两个数字差这么多是因为逐高斯有大量"接近 0 的噪声对比"，不掩盖分块级的一致性。报告必须注明层级。
- 排序稳定性作为独立结论：跨 5 个向量，rigid_err 与 delta_protrusion 排序 100% 一致；shape_err 只有 extreme 上出现 TGA 优于 LAM 的翻转 → shape_err 作代价项使用时必须声明"极端表情下 TGA 谱形更接近解析解，但方向错误率更高"。

### 4.4 样本量建议（几何指标）

用实测 design effect 反推 80% power 所需块数：

| 比较 | 指标 | 所需块数（80% power） |
|---|---|---|
| TGA − RotSync | rigid | 6 |
| TGA − RotSync | shape | 13 |
| RotSync − LAM | rigid | 9 |
| RotSync − LAM | shape | 15 |

现有 K=155 远远充分（10–25 倍余量）。结论：几何指标的样本量不是瓶颈，瓶颈是指标效度与跨表情/跨身份泛化。

跨身份泛化才是真正的样本量问题：
- 当前只有 1 个身份（messi）、1 个重建。结论不能外推到"任意身份"。
- 建议至少 5 个身份（sample_input 里有 11 张不同人，可用），每身份 × 5 向量；身份作随机效应（5 水平勉强），报"身份间排序一致率"。若某身份上排序翻转 → 结论不稳健，必须报告。

### 4.5 主观实验的样本量与检验

见 §3.3：32 人 × 18 clip × 3 对 ≈ 1728 判定，GLMM 分析。
- 主检验：GLMM 的 method_pair 主效应，α = 0.05/3（3 对，Bonferroni 足够）。
- catch trial 是质量门，不是检验。
- 报偏好率 + 95% CI（cluster bootstrap over subjects, B=5000），这是审稿人最认的形式。

### 4.6 一个容易犯的错

"PSNR 23.442 vs 23.466，差 0.024 dB，做个 t 检验 p<0.001 所以显著。" —— 这是伪显著。像素级差异的样本单位是像素，像素间 ICC 极高（同一三角形内像素完全相关），design effect 可达 10²–10³。真实检验单位是帧或序列，而它们只有 9 个。9 个样本检不出 0.024 dB，也不该检出 —— 这正是参考系 C 只能给"7 个向量排序稳定"这种弱证据的原因。若要在像素层面下结论，唯一合法路径是 §1.3 (N6) 的 warp error + 更大的效应。

### 5.2 综合判定逻辑（决策树）

```
IF 任一 G1–G4 不过:
    → 不上线。先修（G2 用 fallback，G3 用自适应 max_angle）
ELSE:
    IF G10（主观）不过:
        → 不上线。说明"几何改善但人看不见"，回到 §2.5 可见性定标，
          检查是不是指标与主观脱钩（而不是方法不行）
    ELSE:
        IF G5–G9 全部 Pareto 不差 且 至少 3 项显著更好:
            IF 相对上一版（RotSync）在 G5'/G10b 上显著更优:
                → 上线（M4 通过）
            ELSE:
                → 不上线（与 RotSync 等价，无理由增加复杂度/风险）
        ELSE:
            → 有条件上线：作为 opt-in 档位（rotation_gain=0.8 的保守版），默认仍用 RotSync / LAM
```

### 5.3 分阶段上线建议（如果 G2 短期修不好）

现实判断：G2（尾部）的修复成本远大于主体收益的取得成本。

| 阶段 | 上线内容 | 前置条件 | 风险 |
|---|---|---|---|
| P0（立即可做） | RotSync 作为 opt-in 档（不改默认） | G1/G4/C1–C5 通过 | 低：默认行为不变 |
| P1（1–2 周） | 修 G2：无解区 fallback 混合 | unresolved_rigid_p99 ≤ 60° | 中：需验证 fallback 不引入帧间跳变 |
| P2（1 月） | 打开 coherence_gate 或自适应 max_angle | G3、G7、G8 通过 + 主观 G10 | 中：门控可能造成局部"冻结" |
| P3（可选） | 改进方向 (b) 轴级部分拉伸 / (c) SPD 测地插值 | 先由 G7 判定 (a)/(c) 是否有必要 | — |

(a) 与 (c) 的取舍应由 G7 一个数决定：若 Δε 的 p90 < 2°，则"法向协变修正"与"测地插值"都被证明是不可见量级的优化，应直接砍掉，把预算投到 G2/G8。该实验成本约 2 小时（复用 eval_protocol_stats.py + tga_covariance.vertex_jacobians），建议在写任何新代码之前先做。

### 5.4 一句话验收判据（给决策者）

> "方法四值得上线"当且仅当：在 155 个空间分块上配对 bootstrap 显示 rigid_err 中位下降 ≥ 60% 且 CI 下界 ≥ 50%，penetration 与 delta_protrusion 显著优于 TGA，shape_err 上升 ≤ 8%，尾部 p99 ≤ 60°（即无解区已处理），Ω 落在 [0.97, 1.03]，saturate_frac ≤ 2%，单帧 ≤ 30 ms，并且 32 人 2AFC 相对 LAM 的偏好率 ≥ 65%（CI 下界 ≥ 58%）。任一否决项不满足，则只能作为 opt-in 档上线，不改默认。

## 附录 C：现有数据的必要说明（诚实条款）

1. 样本范围：全部数字来自 1 个身份（messi）、1 次 LAM 重建、5 个合成表情向量 + 9 个 ARKit preset。不能外推到其他身份、其他输入图、真实视频驱动。
2. shape_err 的排序在 extreme 上翻转（TGA 0.8030 < LAM 0.8429 < VTP 0.8715 ≈ RotSync 0.8722）。若把 shape_err 当质量指标会得出"TGA 最好"的错误结论。它必须在代价项栏里读。
3. normal_angle 绝对值无效已确认（约等于随机基线），但差分有效，两者不要混用。
4. eig_rel_err_p99 对 RotSync 是 0（float32 地板），这是构造性质，不是性能证据。不要当主要卖点。
5. rigid_err 的 p50 改善幅度（−80%）与 p99 改善幅度（−5%）严重不匹配，这是本文档最重要的单一事实，所有验收阈值必须围绕它设计。
6. 像素指标（参考系 A/C）的所有差异都在噪声内（A 跨度 5.3e-4 dB，C 跨度 0.024 dB），把它们当排序依据就是重犯参考系 A 的错误。
