## 1. 口径声明（读表前必看）

rigid_err 严格照抄 `lam3d/scripts/eval_cov_offline.py:150-193`：对有向边对（src/dst 各含正反两向）做 Kabsch 得 `r_ref`，方法侧 `r_delta = R1 R0ᵀ`，`rigid_err = angle(r_ref, r_delta)`，`angle(a,b) = degrees(arccos(clip((tr(aᵀb)-1)/2,-1,1)))`。**不是**比较 R1 本身（那样会得到 ~175° 的无意义数字）。

两条必须知道的口径事实：

1. **F0 的 npz 不可复现，只能复现 lam/vtp。** 用 HEAD 的 `lam3d/core/rot_sync.py`（mtime 14:00:11，晚于 npz 的 12:05:47，属代码漂移）重算，lam 与 vertex_then_polar 与 npz **逐位吻合**，rot_sync 五个 preset 全部 mismatch（如 ones：本文 p99 115.06 / n60 1124 vs npz 52.77 / 179）。npz 时代 rot_sync 的 p50 与 vtp 完全相同，说明当时的 face 通路行为接近 vertex 通路；HEAD 的 face 通路明显劣化。**所有 F0 数字用本文重算值，不要混用 npz 的 rot_sync 行。**
2. **参考系选择本身值 10-68° p99。** 额外用面积加权 Markley 环平均（即 rot_sync 内部构造该场的方式）当参考重测：kabsch 参考与 markley 参考自身分歧 p99 = 43.47/26.31/67.64/21.34/10.19°（n60 116/61/251/41/24）。在这个替代参考下 rot_sync 的 extreme p99 从 158.27 降到 121.19，而 vtp 从 99.55 升到 164.99 —— **两种参考下方法排序直接翻转**。所以「rot_sync p99 158°」有相当部分是它与评测 Kabsch 参考的口径差，不是纯粹的形变错误。G2 判据下的数值严格成立，但它衡量的是「与 eval 协议参考系的夹角」。

## 2. 方法

所有 fallback 都作用在**四元数测地线**上（`slerp` 已按 `rot_sync.py:174` 的 `slerp_identity = Exp(t·Log q)` 修正；旧版错用 `2·arccos` 把旋转角当插值角，会系统性低估 t。脚本内含 `check_slerp_identity` 自检：t∈{0,0.05,…,1.0} 上角度误差 ≤ 2.97e-10°）。

- **F0** = RotSync 原样（face 通路，`max_angle_deg=45`, gate=0）。
- **F1** = RotSync 内建 coherence gate：`g = clamp((R-τ)/(1-τ), 0, 1)`，用 `slerp(identity, q_rot_sync, g)` 向恒等回缩（R 为一环合矢量长度，随 `delta_rotation_scale` 的 diag 返回）。
- **F2** = 在 gate 打开处回落 LAM delta：`slerp(q_lam, q_rot_sync, g)`。
- **F3** = 回落 VTP（`vertex_then_polar` 通路）。
- **F4**（附加）= 分歧触发：`t = clamp(1 - angle(R_m, R_rot_sync)/θ, 0, 1)`，θ∈{30,60,90,120}。
- **F5**（诊断）= 全局常数混合 `slerp(q_vtp, q_rot_sync, α)`，α∈[0,1] 扫 11 点；α=0/1 为退化端点（分别等于全 VTP / 全 RotSync）。
- **ORACLE2/3** = 逐高斯取 min 误差（不可实现，作下界）。
- τ ∈ {0.3, 0.5, 0.7, 0.9, 0.95, 0.99} 六点。

## 3. 机制一：τ→1 不是「找到好 gate」，而是「少用 RotSync」

这是本报告最重要的机制结论，否则 τ 调优会被误读。

coherence 的绝对值**几乎处处接近 1**：p50 = 0.9997 / 0.99993 / 0.9988 / 0.99988 / 1.0；`frac_lt_0.3` = 0.11% / 0.06% / 0.20% / 0.06% / 0.005%；`frac_lt_0.7` = 1.3% / 0.55% / 2.5% / 0.38% / 0.21%。

于是 gate 几乎不在任何地方「关闭」，F1/F2/F3 实际上是**全局平滑插值**。证据是 `frac_fully_gated`（t ≥ 0.99 的顶点占比）与 `mean_t`（乘到 r_delta 上的平均缩放）：

| τ | frac_fully_gated (extreme) | mean_t (extreme) |
|---|---|---|
| 0.3 | 0.6576 | 0.9558 |
| 0.5 | 0.6232 | 0.9399 |
| 0.7 | 0.5746 | 0.9102 |
| 0.9 | 0.4868 | 0.8263 |
| 0.95 | 0.4388 | 0.7612 |
| 0.99 | 0.3628 | 0.6018 |

τ=0.3 时 66% 的高斯已经被「全额关掉」了（对 ones 更极端：78%）。所以 τ 单调变好只有一个解释：**唯一稳赚不赔的做法就是少用 rot_sync**，而 τ=0.99 已经逼近「完全不用」（F3_vtp_tau0.99 与 VTP 原样的差别只剩 ones 的 48.52 vs 48.52、rand 的 22.76 vs 22.61）。**这不是找到了修 tail 的门控，是把 rot_sync 让位给了另一个方法。**

顺带解释了 F2 为何弱于 F3：rot_sync/vtp 的施加角被 `max_angle_deg=45°` 硬截断（extreme 有 14.9% 顶点顶到 45°，p99 恒为 45.00），而 LAM 不截断、max 可达 125.25°。所以「回落到 LAM」等于回落到一个更激进、尾部更不可控的场。

## 4. 机制二：尾部 = 参考系不稳，不是「一环内有 176° 矛盾」

任务书的前提是「一环的面旋转两两夹角中位 176°，任何平均法都无解」。复核结果：**方向对，数值夸大**。

- 用**正交**面基（`b1 = e1/|e1|`, `b2 = n/|n|`, `b3 = b1×b2`）算逐面旋转后，逐面转角 p50 只有 6.55 / 3.24 / 13.40 / 3.89 / 0.20°。
- 逐顶点一环内两两夹角是**双峰**：全population 中位 4.81 / 2.37 / 9.66 / 3.02 / 0.26°，但**在 tail 上是 56.76 / 61.91 / 59.49 / 64.40 / 53.85°**（≈60°，正好与 G2 门槛同量级）；tail 上 >90° 占 23-27%，>150° 只有 0.4-1.6%，**>170° 全 preset 为 0**。
- 一环分歧是极强的尾部预测器（rank-AUC 0.944-0.991）。
- **踩坑教训（勿重犯）**：如果用非正交基 `(e1, e2, e1×e2)` 直接做 `F1·inv(F0)` 再算角度，会得到逐面角 p50 = 117-118°、frac>90 = 0.65 的**假象**——极分解后的「旋转」已不是旋转，那次极分解本身在拟合剪切。最初的 115-158° 就是这么来的。176° 这个数字极可能是同源假象。

更硬的机制证据来自 reference-stability（`refstability.json`）：把同一静息邻域分别用 1-ring 与 2-ring 做 Kabsch，两者相差 ≥5° 即判为「参考不稳」。结果：

| preset | frac_stable | p99 on stable | p99 on unstable | tail contained |
|---|---:|---:|---:|---|
| ones | 0.410 | 5.60 | 134.02 | True（0 残留） |
| half | 0.517 | 5.07 | 85.76 | True |
| extreme | 0.366 | 5.20 | 165.67 | True |
| rand | 0.483 | 6.29 | 68.50 | True |
| rand_sparse | 0.705 | 4.17 | 62.57 | True |

**尾部 100% 落在参考不稳集合里；把稳定子集单独取出来，F0 的 p99 立刻掉到 5.0-6.3°（远低于 60°）。** 2-ring 条件数 p50 = 72.95、p90 = 741、p99 = 6945（deg1 p50 = 6 / max = 32），corr(err, instability) = 0.76-0.84。即：不是「一环里旋转互相矛盾所以平均不出来」，而是**这片区域的旋转在静息网格上就没有唯一解**（网格退化 + 大形变导致面积伸缩 edge-ratio p99 达 4.23）。

尾部也不是某个解剖局部：extreme tail 的质心就在外接球中心附近，tail 到中心半径 p50 0.065 vs 全体 0.068；尾部集合跨 preset 的 intersection 只有 19/20018 个顶点（union 2946，jaccard 0.02-0.36），随表情向量大幅漂移。

## 6. GSDeformer splitting：文献评估（未实现，仅评估）

文献：Huang, Xu, Yu, Lee, *GSDeformer: Direct, Interactive Gaussian Splatting Deformation*（arXiv **2405.15491**v5；Bournemouth + NCKU）。

论文机制（照原文核对）：高斯 → 椭球 → 6 个主轴交点 + 中心共 7 个代理点 `AP = {c, x1,y1,z1, x2,y2,z2}` → 由源 cage 到目标 cage 的 MVC 得到每点位移 → 逐高斯最小二乘 `T = D_d D_sᵀ (D_s D_sᵀ)^{-1}`（`D ∈ R^{3×6}`）→ `μ_d = c_d`, `Σ_d = T Σ_s Tᵀ`。**splitting 判据**：逐轴比较变形后 `(x1'-c')` 与 `(x2'-c')` 的夹角，低于阈值就沿该轴分裂；**阈值 175°**，并跳过轴长 < 1e-2 的轴；分裂时各轴乘因子 k，体积守恒 `k1k2k3 = (1/2)^{1/3}`，实践 k=1/2 略优，可多次分裂。性能：~60 FPS 变形、>200 FPS 渲染（A5000 + 3975WX）。

**必须指出的前提问题**：任务书写「论文报告 splitting 后高斯数增幅 < 1%」。原 PDF 中搜 "1%"、"percent"、"overhead"、"number of Gaussians"、"splitting threshold" **全部 0 命中**，该数字无出处，不得引用。

本资产上的实测评估（阈值 175° 原判据，两种场）：

| preset | exp_children（旋转场，下界） | exp_children（位移场，主结果） | straddle p50（三轴，°） | straddle >45° | straddle >60° | tail_fixable_frac |
|---|---:|---:|---|---:|---:|---:|
| ones | 1.270 | 3.484 | 3.74 / 3.46 / 3.57 | 0.063 | 0.028 | 0.891 |
| half | 1.124 | 2.918 | 1.86 / 1.71 / 1.77 | 0.009 | 0.003 | 0.920 |
| extreme | 1.476 | 3.977 | 7.62 / 7.05 / 7.31 | 0.161 | 0.110 | 0.868 |
| rand | 1.103 | 2.908 | 1.94 / 1.98 / 1.90 | 0.004 | 0.001 | 0.982 |
| rand_sparse | 1.046 | 2.098 | 0.12 / 0.20 / 0.17 | 0.003 | 0.001 | 0.905 |

（`straddle_deg` = 跨高斯直径两端最近的静息顶点的 skinning 旋转差，与任何插值场无关，是这个资产上最干净的「足迹是否跨越旋转差」诊断。`exp_children = Π(1 + frac_j)` 是单轮期望子代数；`k_per_split = 2^{-1/3} = 0.7937` 保体积。）

**评估结论（四条，逐条对应任务书的四个候选）：**

1. **不必要。** 高斯足迹跨越的旋转差中位只有 2-11°（extreme 7.6/7.1/7.3°，p90 = 49.3°），远低于 60° 门槛；只有 0.3-16% 的高斯任一轴 >45°。分裂是给「一个高斯跨过了剧烈旋转差」准备的药，而这批资产上尾部的成因是第 4 节的**参考系不稳**，不是足迹太大。
2. **昂贵。** 按论文原判据（175°）在位移场上跑，单轮就让高斯数变 2.1-4.0 倍（extreme 3.977×）。任务书假设的「<1%」在本资产上差两个数量级。
3. **不收敛。** 递归分裂（6 轮）全部撞上限 2^18：children_mean 52599/39482/67799/41973/21230，mean_splits 7.59/6.25/8.82/6.34/4.08，`converged = False`。逐轮把阈值等价收紧（scale 1.0→0.79→0.63→0.50→0.40→0.32）后，aperture 只从 [7.76,15.73,11.08] 降到 [3.54,12.37,6.31]，frac>5° 从 0.55 只降到 0.47 —— **孔径由变形场的曲率主导，缩小轴不会让它消失**。所以只能引用**单轮**的 2.1-4.0× 作为诚实成本。
4. **即使有效也不对症。** `tail_fixable_frac`（尾部中分裂跨度 > 60° 因而理论上可被分裂改善的比例）只有 0.868-0.982，而那是用「旋转差 > 60°」这个粗代理判的；换算成真实收益，需要把 2874 个尾部高斯各拆 2-4 份，而 ORACLE4 已经证明 60° 的下界卡在 60.9°。**收益与代价比在本资产上是负的。**

**结论：splitting 不纳入方案，也不建议实现。**（附带说明：本资产没有论文要求的粗 cage，`splitting_criterion` 用一个由真实变形顶点驱动的 IDW 位移场 `f` 代替 MVC，docstring 已声明这一差异；它只能作量级参考，会高估分裂需求，因为资产 gs_scale p50 = [0.00042, 0.00232, 0.00111] 每个高斯都比边长中位 0.00308 更大。）

## 7. 建议

1. **不要**为了 p99 去调 coherence gate 的 τ。τ→1 的收益来自「少用 rot_sync」，直接换方法即可，不需要引入一个名字叫 gate 的插值器冒充选择器；且 τ=0.99 时 F1 的 p50 已恶化 0.505°、F2 恶化 1.312°，越过 +0.5° 辅助容差。
2. 若要压 p99，**真正有效的是按参考稳定性做硬选择**（1-ring vs 2-ring 差异 ≥5° 时不用几何平均场），稳定子集的 p99 只有 4.2-6.3°。这是唯一在数据上通过的路径，但它需要改 `rot_sync.py` 的场构造（本任务不改既有文件），应作为下一阶段方案。
3. 报告层必须写清口径：G2 FAIL 成立，但 extreme p99 这个数含 10-68° 的参考系选择成分（第 1 节），且尾部不是固定顶点集（跨 preset jaccard 0.02-0.36）。
4. 生产上 F3_vtp_tau0.99 可作「比现状好 1.6 倍」的工程折中（extreme 158.27 → 99.55，p50 无损失），但**它不是 fallback，是换方法**，请如实标注。
