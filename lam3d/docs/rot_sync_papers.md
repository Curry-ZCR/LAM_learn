# 高斯旋转同步 · 论文机制对照

> 目的：为 LAM（arXiv:2502.17796）单图表情数字人方案的「方法一：高斯旋转同步」提供**可核验**的机制出处。
> 约束：LAM 的高斯绑在 **20018 个 Loop 细分顶点**上（5023 → 20018，每顶点一个高斯），驱动只改高斯中心（LBS + 逐顶点偏移），**四元数原样拷贝**。
> 用户实测高斯极度各向异性：轴长比 **p50 = 3.37，p90 = 83**（本仓库实测数据，非论文）。
> 本文件所有引文均来自 arXiv 正文（/abs 与 /html）或官方项目页；未能核实的条目集中列在 §5。

## 2. 逐篇机制

### 2.1 GaussianAvatars（SIGGRAPH 2024）— 面局部帧的原始定义

- **参数化空间**：§3.2 "3D Gaussian Rigging"。每个三角面配**一个**高斯；三角面局部帧：原点 `T` = 三顶点均值，`R` 的列向量 = 一条边方向 / 三角面法向 / 二者叉积；标量 `k` = 一条边与其垂线长度的平均。高斯的 `μ, r, s` **全部定义在这个局部空间**，初始化 `μ=0, r=I, s=1`。
- **驱动时旋转怎么算**：逐面刚性。范式（原文 Eq.4–6）：
  ```
  r' = R · r        μ' = k · R · μ + T        s' = k · s
  ```
  `R` 直接从**形变后的三角面顶点**算出，因此**已经包含全局头部姿态 + 局部表情**两部分。这就是报告 §5.1 所说的"不能重复计算"的落地示范：不要再在渲染前额外乘一次 head pose。
- **刚/非刚性分解**：**没有显式分解**。形变中所有非刚性（拉伸、剪切）都被 `k` 这个**各向同性标量**吸收 → 相似变换。SurFhead §2.2 正是批评这一点：base/height 长度取平均，无法表达 shear/stretch。
- **退化 / 稳定性**：§3.4 两条正则（只对可见高斯）：
  - `L_position = ‖max(μ, ε_position)‖₂`，`ε_position = 1`
  - `L_scaling = ‖max(s, ε_scaling)‖₂`，`ε_scaling = 0.6`，`λ_position = 0.01, λ_scaling = 1`
  论文给的理由很关键：**"若高斯比父三角面大很多，三角面极小的旋转会被高斯尺度放大成抖动"**；不施加时会出现 "large spike- and blob-like artifacts"。→ 这是"旋转同步必须配尺度上限"的最直接依据。
  - 还强制**每个三角面至少保留一个高斯**（否则眼部等常遮挡区会被剪空）。扁平/法向退化：**论文未提及**。
- **局限**（原文）：FLAME 未建模的头发、饰品不可控。

### 2.2 SurFhead（ICLR 2025）— 极分解 + 法向协变

- **参数化空间**：仍是**面局部**，但用 **2D Gaussian surfel**：`R := [r₁; r₂; n]`，`n := r₁ × r₂`，尺度 `(s₁, s₂, 1)`。切向叉积**闭式**给法向，因此法向永远与切平面正交（构造性保证，不是学出来的）。
- **驱动时旋转怎么算**：定义面变形梯度
  ```
  E  = [v₁−v₀, v₂−v₀, v₃−v₀],   v₃ := v₀ + (v₁−v₀)×(v₂−v₀) / sqrt(‖(v₁−v₀)×(v₂−v₀)‖)
  J  = Ẽ · E⁻¹                    (Sumner & Popović 2004)
  Σ^{1/2} = J · R_c · S_c,   Σ = Σ^{1/2}(Σ^{1/2})ᵀ
  ```
  替代 GaussianAvatars 的 `s_p·R_p·R_c·S_c`。附录 A.2.2 证明在 `J` 的梯度下 `Σ` 仍保 PSD。
- **法向（最关键的一条）**：`n_d = J^{-T} n_c`，原文强调 "Orthogonality must be maintained in any space"，前提是 **J 非奇异**。
  → 对"扁高斯斜插出皮肤"的严格解释：法向是**协变**的，必须用**逆转置**传播。只同步旋转、不同步法向，薄片方向就与真实表面法向解耦。
- **刚/非刚性分解**：有。§2.3 **JBS（Jacobian Blend Skinning）**：先把 `J` 极分解为 `J = U·P`（`U` 正交旋转，`P` 对称半正定 stretch/shear；附录 A.2.1 证明**唯一且与坐标系无关**），然后
  - 旋转：`U_b = exp( Σ_i w_i · log U_i )` —— 在 **so(3) 对数空间**加权，再 exp 回 SO(3)
  - 拉伸/剪切：`P_b = Σ_i w_i P_i` —— 在**线性矩阵空间**加权（因此保 PSD）
  - `J_b = U_b · P_b`
  混合范围 = 父三角面 + 相邻三角面。论文明确批评"逐元素线性混合相邻面变换"（Zielonka/INSTA 一类）会产生几何畸变（Fig.2b）。
- **退化 / 稳定性**：`J^{-T}` 要求 `J` 非奇异，论文把它当**前提**给出，**未讨论**近退化（细长三角面、面积趋零）时的兜底；扁平高斯的处理**论文未提及**（见 §5）。

### 2.3 GeoAvatar（ICCV 2025）— 分区 + 极坐标正则

- **参数化空间**：与 GaussianAvatars 同构的**面局部帧**。每个 FLAME 面挂一组高斯 `G_{i,j}`，局部参数 `{μ, r, s, c, α}`；全局化（Eq.2）：
  ```
  T: μ ↦ S_face·R_face·μ + C_face,   s ↦ S_face·s,   r ↦ R_face·r
  ```
  即旋转是 `R_face · r` 的**左乘合成**，与 GaussianAvatars 完全一致。
- **驱动时旋转**：逐面刚性，与 GaussianAvatars 相同。**旋转不是本文贡献**。
- **核心贡献（对本方案最有用）**：**APS（Adaptive Pre-allocation Stage）** 把 FLAME 面段无监督分成 **rigid 集 F_r / flexible 集 F_f / mouth 结构集 F_m**，用 part-wise 的 `mean ‖μ‖` 作阈值 `τ_part`。
- **退化 / 稳定性**（§3.3，对 `μ` 的极坐标 `(r, φ)`）：
  - `L_p(r) = ReLU(r − τ_p)`，`τ_r = 0.1`（刚性集几乎贴面）、`τ_f = 2.0`（柔性集允许远离）、`τ_m = τ_r`
  - `L_angle(φ) = 1_{r > τ_r} · ReLU(φ − τ_φ)`，`τ_φ = 45° ≈ 0.78 rad`：防止柔性高斯的**方位角**跑到邻面去（否则"表示唇部皮肤的高斯绑到了鼻子"）
  - 四元数符号 / 半球对齐：**论文未提及**。
- 口腔建模：补了磨牙、上颚、口腔底（GaussianAvatars 只有门齿），同一 part 内施加**一致的偏移**。

### 2.4 SplattingAvatar（CVPR 2024）— 顶点帧 + 重心插值（与 LAM 的绑定粒度最接近）

- **参数化空间**：三角面**重心坐标** `(u,v)` + 沿插值法向的位移 `d`（Phong surface：`P = V(k,u,v)`，`n = N(k,u,v)`，`μ = P + d·n`）。嵌入 `E = {k,u,v,d}`，号称"网格表面周围的一阶连续空间"。
- **驱动时旋转**：
  1. 对规范/姿态空间的三角面分别用 `(tangent, bitangent, normal)` 得 `R_cano, R_pose`；
  2. **`R_k = R_cano · R_pose⁻¹`**（这是"面从规范到姿态转了多少"，属于**相对旋转**，天然不含全局姿态）；
  3. 转四元数后按**邻接三角面面积加权**平均成每顶点四元数：`q_V = Σ A_k q_k / Σ A_k`；
  4. 每高斯：`δq_{i,t} = u·q₁ + v·q₂ + (1−u−v)·q₃`（**重心插值**），`q_{i,t} = δq_{i,t} * q̄_i`（乘在规范旋转上），`s_{i,t} = (A_pose/A_cano)·s̄_i`。
- **刚/非刚性**：靠 `R_k` 的**相对**定义把全局姿态消掉；没有显式刚/非刚分解，非刚性由学习的高斯残差承担。
- **稳定性**：Eq.5 的加权和**未提四元数半球对齐**（原文就是逐元素加权求和，不是 SLERP/nlerp）；扁平/退化处理**论文未提及**。→ 见 §5「未核实」。

### 2.5 Rig3DGS（CVPR 2024）— Kabsch 刚性 + MLP 残差，带距离门控

- **参数化空间**：canonical 空间（不绑面）。形变由 FLAME 的 **K 近邻顶点形变加权和**给出：`Def(x_can) = Σ_{j≤K} w_j δv_j`，`w = F(x_can)`（MLP），再加残差 `T(i), η`。
- **旋转**（§3.3）：`R_def = R_can · R'`，其中 `R' = R_mesh · R*(x_can, DWAvg({δv_j}))`；
  - **`R_mesh = Kabsch(v_{j,can}, v_{j,def})`**：对 K 近邻点做**最小二乘刚体拟合**（等价于对 3×3 相关矩阵做极分解 / Procrustes）→ 逐块刚性旋转；
  - `R*`：小 MLP 预测的**非刚性残差旋转**；`S_def = S_can × S*`（乘性残差）。
- **刚/非刚性分解**：这是三篇之外最干净的范式——**Kabsch 给刚性主项，MLP 给残差**；且用正则按"到网格距离 D"门控：离网格 > D 的点强制 `R→I`（`L_Global,Rot`，λ=1e-1）、`S*→1`（λ=1.0），形变本身也正则（`L_η` λ=1e-3、`L_T` λ=1e-3、`L_Global,Def` λ=1e-1）。
- **稳定性**：见上述门控；扁平高斯**论文未提及**。

### 2.6 FlashAvatar（CVPR 2024）— 全学出来的旋转残差

- **参数化空间**：**UV 空间**均匀采样，再按固定重心坐标嵌到 FLAME 表面（论文明确：按顶点初始化不收敛，见 Fig.10；UV 更均匀）。为建口腔加了额外面。
- **驱动时旋转**：位置 `μ_M` 由固定重心坐标加权顶点得到（刚性传递）；旋转**不是**网格传递，而是 offset MLP 学残差
  ```
  Δμ_ψ, Δr_ψ, Δs_ψ = F_θ(γ(μ_T), ψ)          (Eq.5)
  (μ, r, s) = (μ_M ⊕ Δμ_ψ, r ⊕ Δr_ψ, s ⊕ Δs_ψ)   (Eq.6)
  ```
  `⊕` 在原文中未给出逐元素定义（加法 / 四元数乘 **未核实**，见 §5）。
- **稳定性**：无旋转正则；自述局限是"依赖好的表面嵌入初始化，**全局姿态误差会造成细节丢失/图像错位**"，且无法建模剧烈非刚性（飘发）。→ 反证"纯学习式旋转同步不抗姿态误差"。

### 2.7 LAM（基线，arXiv:2502.17796）

- **参数化空间**：**顶点绑定 + 规范空间**。规范高斯属性生成器以 FLAME 规范点为 query（多尺度图像特征 + Transformer）预测高斯属性；FLAME Subdivision 用"每边中点 / 每面四分"细分，**blendshape 属性按边两端平均值一起细分**，并施加到每个高斯点上。**没有局部帧**，与 GaussianAvatars 的"面局部帧"根本不同。
- **驱动时旋转**：论文用标准 **LBS + corrective blendshape** 动画高斯位置，**不涉及高斯朝向**（与源码一致：`gs_rotation` 原样 expand）。→ 这就是"位置动了、朝向没动"的来源。
- 论文未明确写明"每个细分顶点恰好一个高斯"（**未核实**，源码观察是如此）。

## 4. 可直接落地的结论（8 条）

1. **坐标系统一用「面局部帧」，但 LAM 是顶点绑定，所以要先把面帧平均成顶点帧。**
   GaussianAvatars/GeoAvatar 都是"1 高斯/面"，可以直接用该面的 R；LAM 每个细分顶点一个高斯，必须先对该顶点的 one-ring 面做 `R_v = exp(Σ w_f log R_f)`（参考 SurFhead JBS），再对高斯用。**否则同一个面上多个顶点会得到互相打架的朝向。**
2. **"只改旋转、保轴长"在数学上等于取 deformation gradient 的极分解旋转部分 `U`。**
   SurFhead §2.3 的 `J = U·P` 唯一且与坐标无关。因此方法一的 `Σᵗ = Rᵗ Σ⁰ Rᵗᵀ` = 只保留 `U`、丢弃 `P`。**代价**：GaussianAvatars 用 `k` 近似 shear、SurFhead 明确批评这一近似——保轴长会牺牲拉伸/剪切，但换来"薄片不被拉长"。**建议默认取 `U`，把 `P` 降级为可选开关**。
3. **法向必须单独传播，不能只靠旋转。**
   `n_d = J^{-T} n_c`（SurFhead §2.2，"Orthogonality must be maintained in any space"）。这正是"薄片斜插出皮肤"的严格根因：把 `R` 同步对了，法向仍可能偏；有 `J` 时一律用逆转置，只有旋转时至少用 `n' = R·n` 并对齐到插值法向。
4. **混合必须在 so(3) 对数空间做，不能逐元素线性插值矩阵或四元数。**
   SurFhead §2.3 明确：线性混合相邻面变换会产生几何畸变（Fig.2b）；正确做法是 `exp(Σ w log U)`。若坚持四元数实现，**必须先半球对齐（`q·q_ref<0` 则取反）再加权归一化**，否则最短路径会反转——SplattingAvatar 的面积加权和原文**未提**这一步（可改进点）。
5. **全局姿态与局部表情必须显式分离（对应报告 §5.1 / §8.2）。**
   GaussianAvatars 的 `R` 是"LBS 后的三角面"算出来的，已经含全局头部姿态；如果渲染管线又乘一次 head pose，就是重复计算。落地：**在帧定义处取相对量** `R_k = R_cano⁻¹ R_pose`（SplattingAvatar 的做法），或者把基线变换 `B` 先除掉，只让残差 `C = J·B⁻¹` 作用在局部帧上。
6. **刚性/非刚性分解照 Rig3DGS 的"主项+残差+门控"写。**
   `R_def = R_rigid(网格/Kabsch) · R_residual(MLP/手工)`，并给每个高斯一个**绑定可信度** `w_bind`：离表面越远（头发、眼镜）越衰减旋转同步强度，超过阈值直接 `R→I`（Rig3DGS 的 `L_Global,Rot`）。**LAM 的逐顶点高斯里存在大量偏离表面的，这一条必须有。**
7. **保轴长之外还要有尺度/偏移上限，否则极端各向异性会被放大成尖刺。**
   GaussianAvatars §3.4 的 `ε_scaling = 0.6`、`ε_position = 1` 明确针对"高斯远大于父三角面 → 微小旋转被放大成抖动"。你实测 p90 轴长比 83，**必须对 `s` 与逐顶点偏移做 clamp**，并对 `w_bind` 之外的离群高斯单独降权。
8. **退化要显式兜底，不要假设 `J` 可逆、四元数一定数值健康。**
   SurFhead 的 `J^{-T}` 以 `J` 非奇异为前提（论文未给兜底）；实现上应：`|det J| < ε` 或三角面面积 < ε 时**回退到 one-ring 平均法向 / 单位旋转**；`q·q < ε` 时重归一化；`log U` 在 θ→π 附近用四元数向量部分 `sin(θ/2)·n` 代替以避免分支奇点。
