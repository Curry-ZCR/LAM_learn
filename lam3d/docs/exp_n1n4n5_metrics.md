任务书：`lam3d/tasks/stage1_sc_n1n4n5.txt`（Stage-1 自检，指标编号 N1/N4/N5）。
脚本：`lam3d/scripts/exp_n1n4n5.py`（本次新增，唯一入口）。

|---|---|

| 网格 | FLAME 表情态网格，39904 面 |
| 局部边长 ē | **1.6208 mm**（网格三角面边长中位数，实算；probe_protrusion.py 注释里的 5.308 mm 是旧资产口径，本报告不用） |
| planar 掩码 | `s0.max/s0.min > 2.0` → 85.26% 高斯 |
| eps | 1e-12 |

三个量都只在 **planar 掩码内**统计（薄片高斯无"薄轴"，protrusion 定义对其退化）。

### 1.2 BVH/SDF 采样器（本次实现）

任务书称 `probe_protrusion.py` 含 BVH/SDF 实现，**实际该文件只有解析式**
`prot = s_max · sqrt(1 - (u_thin·n)²)`，没有任何 SDF。故本脚本自带一个等价精度的
向量化 SDF（`MeshSDF` 类）：

1. 三角面质心建 `scipy.spatial.cKDTree`，逐采样点取 k=8 近邻面（k-NN 即粗粒度 BVH 剪枝）；
2. 对 k 个候选面做**向量化 Ericson 点到三角形最近点**（`_point_tri_dist`，Region/Edge/Vertex 三类情形全部用 `np.where` 分支，无 Python 循环）；
3. 取最小距离，符号由该最近面法向给出（`d<0` = 网格内部，与任务书一致）。

校验（脚本内 `sdf_selfcheck`，300 点）：与 `trimesh.proximity` 的 |d| 完全一致
（absdiff p99 = 1.51e-07 m，max = 3.56e-06 m）；符号一致率 0.9167。
> 注意：trimesh 的 `signed_distance` 内部为**正**、外部为**负**，与任务书相反；
> 自检里比对的是 `-ref`。剩余 8.3% 符号分歧全部落在开放边界/非水密的伪法向处。

性能：单帧 2 万点约 0.5 s，比 trimesh 的 rtree 方案快约 60×（后者 2000 点就要 3.0 s）。

### 1.3 N1 penetration（方法间差分 Δθ）

* 逐高斯定义 `cos = |u_thin · n|，prot = s_max·sqrt(1-cos²)`（复用 probe_protrusion.py 语义，
  三个函数 `quat_to_R / pctl / protrusion` 通过读取源码后 `exec` 复用，**原文件一字未改**）。
* **两套 7 点采样都算**：
  * 任务书口径 `axis7_points`：μ 与三轴 ±σ 共 7 点（μ ± x, ±y, ±z）；
  * 协议 §1.3 口径 `thin7_points`：沿薄轴 μ + k·σ_thin·u_thin, k∈{-3..+3}。
* 由 7 点 SDF 得 `embedded = #{d<0}/7`、`pen_depth = max(0,-min d)/ē`、
  `flip = 1[sign(d_{-3σ}) ≠ sign(d_{+3σ})]`、`penetration_rate = mean(embedded > 0.5)`。
* **差分校准是必须的**：`Δprot = prot(表情, 方法 m) - prot(中性, 同一方法 m)`，
  归一化 `dpoe = Δprot / ē`。同一方法内相减，消掉资产/方法共同的绝对偏置。

### 1.4 N4 coverage Ω

主口径按协议：`Ω = Σ_g |det Σ^t_g|^{1/2} / Σ_g |det Σ^exact_g|^{1/2}`，
实现为 `Σ prod(s1) / Σ prod(s0)`（`prod(s)` 即 `sqrt(det Σ)`，s 为三轴尺度）。
辅口径（更贴"覆盖"字面义）：
`Ω_med` = 高斯中心到网格表面距离的**中位数**之比（表情/中性），
`Ω_mean` = 同分布的均值之比。判据 `Ω ∈ [0.97, 1.03]`。

### 1.5 N5 saturate_frac

`saturate_frac = mean(|Δθ| ≥ max_angle - 0.5°) = mean(|Δθ| ≥ 44.5°)`，
`Δθ` 为**实际施加**到高斯的转角（由 `q1` 与 `q0` 反解：`Δθ = 2·acos|⟨q1,q0⟩|`）。
另外记录 `|Δθ| ≥ 44.5°` 的代理比例与 rot_sync/vtp 自带的 `clipped` 标记做交叉验证。
判据：> 2% 不合格；2–5% 需自适应 max_angle；≤ 2% 通过。

M-LAM 的代理值 0.005%–0.27%，即便接限幅也安全。

## 5. 三条关键发现

### 5.1 差分是 N1 成立的前提（绝对量四方法无差别，差分后差 3.5×）

绝对 `penetration_rate` 四方法同为 0.5004、`flip_rate` 同为 0.1103–0.1109；
差分后 dpoe p90 从 LAM 的 1.49e-2 降到 RS/VTP 的 4.2e-3。也就是说：
**方法改进的不是"有多少高斯穿进网格"，而是"表情把高斯推出多少"**。
排序：LAM > TGA > RS ≈ VTP（Δprot p90 LAM 是 RS 的 3.5×）。

### 5.2 TGA 的中性态不恒等（会影响任何跨方法绝对比较）

对 zeros 向量（无表情）调制后实测：

| 方法 | Δθ p50 | Δθ p99 | Δθ max | max\|s-s0\| |
|---|---|---|---|---|
| M-LAM | 1.05e-5° | 3.4e-4° | 2.1e-3° | 7.6e-8 |
| M-TGA | 4.7e-5° | **74.98°** | **162.2°** | 6.8e-7 |
| M-RS | 0° | 3.8e-4° | 1.4e-3° | 0 |
| M-VTP | 0° | 3.8e-4° | 1.4e-3° | 0 |

TGA 在"无表情"下仍有约 5% 的高斯被转了 45°+：`eigh` 在退化/近简并特征子空间里
特征向量方向任意，Σ 不变但 (q, s) 分解变了（`max|s-s0|` 仅 6.8e-7，几乎不动）。
后果：**四方法的中性态 (q,s) 不是逐位相同**（lam vs tga 的 q 最大差 1.772），
所以跨方法直接比 `prot_mm` 绝对值会被 TGA 的中性噪声污染（对 blink/angry 这类小动作
preset 尤其危险，量级相当）。本报告 N1 用"同方法内 表情−中性"的差分，天然免疫此问题。

### 5.3 方法不改中心，Ω_med 的波动纯属算子噪声

`dcenter_mm p50` 在四方法间逐 preset **完全相同**（2.639 / 2.650 / 2.657 / 2.674 / 2.706 /
2.752 / 2.830 / 2.834 / 2.891 mm，对应 blink / angry / smile / bigSmile / sad / kiss /
mouthOpen / laugh / surprise），因为 `modulate` 只动 (q,s) 不动 x（`xb` 三对比最大差 0.0）。
Ω_med 的 4/9 出界来自中位数对"中心距分布形状随表情展宽"的敏感性，而非覆盖缩水。

## 8. 局限

1. **单资产**（messi.png），9 个 preset 是同一张图的 ARKit 系数，结论的横向泛化未验证。
2. **单帧、无声**：每个 preset 只取首帧，未做时间一致性；`temporal_smoothing` 未启用。
3. **N1 只报排序与差分分布**（按任务书要求），不给绝对通过/失败阈值——绝对穿透量是资产属性。
4. **N5 对 LAM/TGA 语义不适用**：二者无 clamp，只能用 `q1 vs q0` 反解的代理量，
   且 M-TGA 的中性态本身带 5% 大转角（§5.2），代理量会把中性噪声一并算进去。
5. `Ω_med` 口径不稳（4/9 出界但非缩水），已弃用为主判据；若后续要用"中心距"口径，
   应改用"分布的分位数向量距离"而非单一中位数比。
6. SDF 符号在开放边界处有 ~8% 的伪法向歧义（自检 0.9167），主要影响 `flip` 与
   `pen_depth` 的极小值端，对 p50/p90 排序无影响。
